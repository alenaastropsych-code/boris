# Борис — бот для сборки PnL по Ozon и Wildberries

## Что делает

Присылаешь боту отчёты Ozon (файл .xlsx «Отчёт по начислениям») и Wildberries
(«Еженедельный детализированный отчёт», обычно приходит в .zip) — Борис сам:

1. определяет, какой это отчёт (Ozon/ВБ);
2. определяет неделю(и), к которой относятся данные — по датам внутри файла;
3. считает суммы по статьям (выручка, комиссии, логистика, реклама и т.д.);
4. сохраняет всё в базу данных (`data/boris.db`);
5. присылает текстовую сводку по неделе + может выгрузить общий Excel-файл
   со всеми накопленными неделями.

Несколько файлов можно кидать разом — они уходят в фоновую очередь и
обрабатываются один за другим, не блокируя бота.

## Команды

- `/start` — приветствие
- `/export` — прислать общий Excel-файл со всем накопленным PnL
- `/week` — сводка за последнюю неделю (или `/week 2026-07-20` — за неделю,
  в которую входит эта дата)
- `/status` — сколько недель и данных уже в базе
- `/cost` — список товаров без указанной себестоимости
- `/setcost <код> <цена>` — задать себестоимость товара, например
  `/setcost 36095832 150`

## Деплой на bothost.ru

1. Создай новый репозиторий на GitHub (или используй существующий
   `super-train`, но лучше отдельный — чтобы не путать с бюджетным ботом),
   и залей туда все файлы из этой папки.
2. В bothost.ru: **Создать проект → Python → подключить GitHub-репозиторий**.
3. В настройках проекта укажи переменную окружения:
   - `BORIS_BOT_TOKEN` — токен бота, который тебе выдал @BotFather в Telegram.
4. Убедись, что стартовая команда — `python server.py` (bothost по умолчанию
   ищет именно файл `server.py` — если у тебя команда запуска указана иначе,
   можно поменять её в настройках проекта на `python server.py`), а
   зависимости ставятся из `requirements.txt` (bothost делает это
   автоматически при деплое).
5. Запусти — бот должен появиться в сети в течение минуты.

### Важно про базу данных

`data/boris.db` — это файл на диске сервера. При каждом передеплое
(`git push`) на некоторых хостингах диск может пересоздаваться — уточни
у поддержки bothost.ru, сохраняется ли `data/` между деплоями твоего тарифа.
Если нет — можно настроить автоматическую выгрузку `/export` раз в неделю
себе в чат как резервную копию, либо перейти на постоянное файловое
хранилище (Volume) в настройках проекта, если оно есть в твоём тарифе.

## Структура проекта

```
boris_bot/
├── server.py                — точка входа, команды и обработчик файлов
├── db.py                   — работа с SQLite базой
├── parsers/
│   ├── detect.py            — определяет тип файла (Ozon/ВБ)
│   ├── ozon.py               — разбор отчёта Ozon
│   └── wb.py                 — разбор отчёта ВБ (в т.ч. из zip)
├── services/
│   ├── queue.py              — фоновая очередь обработки файлов
│   └── export.py             — сборка Excel-файла и текстовой сводки
├── data/                     — здесь лежит boris.db (создаётся автоматически)
└── requirements.txt
```

## Логика расчётов (проверено на реальных отчётах пользователя)

- **Ozon**: суммы берутся из колонки «Сумма итого, руб.», группировка —
  по колонке «Группа услуг». Себестоимость считается только по строкам
  с «Тип начисления» = «Выручка» (внутри группы «Продажи» один заказ даёт
  3 строки с одинаковым количеством — Выручка, Программы партнёров, Баллы
  за скидки, — поэтому для количества товара используется только «Выручка»,
  иначе будет утроение).
- **Wildberries**: «К перечислению Продавцу за реализованный Товар» уже
  нетто (после комиссии ВБ и эквайринга) — остальные статьи (логистика,
  хранение, обработка, удержания) добавляются отдельно, без задвоения.
  «Сумма заказов до вычета комиссии» = «Цена розничная с учётом скидки» ×
  «Кол-во» — справочная строка для расчёта % комиссии ВБ.
- **Себестоимость**: указывается один раз по коду товара (`/setcost`) и
  автоматически подтягивается на обе площадки, если код совпадает.
- **Недели**: считаются Пн–Вс, определяются автоматически по датам внутри
  загруженного файла.
